**Bloks AI has a mark of its own.**

## What changed

- **Bloks AI's own mark.** Wherever Bloks AI appears (choosing an engine, Usage, Plan and limits), it now has a mark of its own in place of a lettered square: the inner ring of the Bloks mark, its four bars turning as the Bloks mark's do, lit by one sweep of the brand's colours round a spark. At small sizes it is drawn with wider gaps, so the turn still shows in a list.
- **A conversation waiting to try again says since when.** When a turn failed and Bloks was waiting to ask again, the list of what is running showed it with no start time. It now shows when that work began.

## For contributors

- **Waiting for idle waits for the changes card too.** The test helper that waits for a conversation to be idle now also waits for an ended turn to finish making its changes card, so a retry or a message sent straight after is never refused for a moment's housekeeping. Thanks @ashottonoyan (#340)
