## What changed

- **Claude Code on your own plan or key.** Claude Code agents always run on your own Claude plan or API key now. Bloks AI runs on Bloks's own engine. An agent that was set to run Claude Code on Bloks AI moves to Bloks AI's own engine when you open the app, keeping its name, memory and everything else, and its conversation says so once. To keep it on Claude Code, sign Claude Code in from Settings, Engines and keys and pick Claude Code for it again. A Claude Code backup engine on Bloks AI is moved the same way, so nothing starts spending your own plan without you choosing it.
- **A word before signing in on a hosted machine.** In a hosted workspace, signing Claude Code, Codex or Gemini in with a personal plan says once, under Sign in, that the plan is priced for one person's ordinary use and that agents working around the clock on it are between you and its maker, with an API key as the alternative. For Codex it also says to turn on device code sign-in in ChatGPT's security settings first. It never stops you signing in.
- **A refused call says why.** When an engine's provider refuses a call, the agent's notice now shows the provider's own sentence instead of a raw error.
