Use this when someone wants to keep track of things that have to happen by a date: renewals, filings, appointments, documents that expire.

1. Keep one list in a file in your folder, each item with: what, the date, how long it takes to do, and where the paperwork is.
2. Add items only from what the person tells you or shares. Ask for the date rather than guessing it.
3. Work back from each date by the time it takes, so a passport that takes six weeks shows up eight weeks before it expires, not the day before.
4. Each time you are asked, or on a schedule, list what is due in the next two weeks and what needs starting now.
5. When something is done, mark it done with the date; do not delete it, so next year's renewal can be found.

Not for: a single reminder for later today. Set that reminder instead.
Return: due soon and start now, each with the date and the first step, then a count of what else is on the list.
Approval: none needed to keep the list. Submitting, paying or booking anything needs approval.
