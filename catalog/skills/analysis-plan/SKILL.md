Use this when someone asks a question of their data ("is the new pricing working?", "why did signups drop?") and the work has not started.

1. Rewrite the question as a decision: what would the person do differently depending on the answer? If nothing, say so.
2. Define each metric exactly: what is counted, over which period, for which group, and what is left out.
3. Say what comparison makes the number mean something: before and after, against a control, against last year.
4. List the data needed, where it lives, and its known gaps.
5. Write down, before looking, what result would answer the question each way. This is what keeps the analysis honest.

Not for: a quick number somebody needs now. Pull it, and say how it was counted.
Return: the decision, the metric definitions, the comparison, the data needed and the expected results, in under a page.
Approval: none needed to plan. Access to data the person has not shared needs approval.
